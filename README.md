# Крок

Навчальна бібліотека для зошитів 8–9 класів. Учні можуть знайти потрібний зошит, а покрокові пояснення до вправ відкриваються за активною місячною підпискою. Каталог наповнюється через адміністративну панель.

## Локальний запуск

Потрібен Python 3.12 або новіший.

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py seed_physics
python manage.py createsuperuser
python manage.py runserver
```

Сайт: `http://127.0.0.1:8000/`. Адмінпанель: `http://127.0.0.1:8000/admin/`.

Команда `python manage.py seed_physics` додає два оригінальні демонстраційні зошити й вісім розв’язаних прикладів українською; запускати її повторно безпечно. Інші зошити додаються в розділі «Зошити»: завантаж обкладинку й до 50 фото сторінок (до 10 МБ кожне), внеси покрокові пояснення до вправ і познач зошит опублікованим. Власник може видати місячний доступ собі кнопкою у списку «Підписки», а іншому користувачеві — вибрати його рядок і запустити дію «Відкрити доступ ще на місяць». Призначати адміністраторів і керувати доступом може лише суперкористувач.

Онлайн-платіжний сервіс ще не підключено, а вміст зошитів не входить до проєкту. Не додавай до відкритого каталогу матеріали, на використання яких немає дозволу.

Для production задай `DJANGO_SECRET_KEY`, `DJANGO_DEBUG=false` та `DJANGO_ALLOWED_HOSTS` через змінні середовища. Локальна SQLite-база та завантажені матеріали виключені з Git.

## Перевірки

```powershell
python manage.py test library.tests
python manage.py check
```
